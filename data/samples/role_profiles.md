# Role Profiles and First-Week Learning Requirements

## Software Engineer
A Software Engineer builds and maintains backend and frontend services, works in two-week sprints, and follows the team code review checklist.
- Mandatory: Get repository and CI/CD access approved. Owner: Engineering Manager. Deadline: Day 2. Role: Software Engineer. Depends on: Set up corporate email and MFA. Category: Software Engineer learning.
- Mandatory: Complete secure coding fundamentals course. Owner: Engineering Manager. Deadline: Day 4. Role: Software Engineer. Depends on: Get repository and CI/CD access approved. Category: Software Engineer learning.
- Recommended: Ship a first small pull request with buddy review. Owner: Buddy. Deadline: Day 5. Role: Software Engineer. Depends on: Get repository and CI/CD access approved. Category: Software Engineer learning.

## Data Analyst
A Data Analyst builds dashboards and reports from the enterprise data warehouse and follows the data governance standards.
- Mandatory: Get access to BI dashboards and data warehouse. Owner: Data Platform Team. Deadline: Day 2. Role: Data Analyst. Depends on: Set up corporate email and MFA. Category: Data Analyst learning.
- Mandatory: Complete SQL and data governance module. Owner: Data Platform Team. Deadline: Day 4. Role: Data Analyst. Depends on: Get access to BI dashboards and data warehouse. Category: Data Analyst learning.
- Mandatory: Complete data privacy classification quiz. Owner: Compliance Team. Deadline: Day 5. Role: Data Analyst. Depends on: Complete Information Security Awareness training. Category: Data Analyst learning.

## QA Engineer
A QA Engineer designs test plans, automates regression suites and tracks defects through their lifecycle.
- Mandatory: Get test environment and defect tracker access. Owner: QA Lead. Deadline: Day 2. Role: QA Engineer. Depends on: Set up corporate email and MFA. Category: QA Engineer learning.
- Mandatory: Complete test strategy and defect lifecycle course. Owner: QA Lead. Deadline: Day 4. Role: QA Engineer. Depends on: Get test environment and defect tracker access. Category: QA Engineer learning.

## Business Analyst
A Business Analyst gathers requirements, writes user stories and coordinates with delivery managers.
- Mandatory: Get access to requirements repository and workflow tools. Owner: Delivery Manager. Deadline: Day 2. Role: Business Analyst. Depends on: Set up corporate email and MFA. Category: Business Analyst learning.
- Mandatory: Complete requirements elicitation playbook. Owner: Delivery Manager. Deadline: Day 4. Role: Business Analyst. Depends on: Get access to requirements repository and workflow tools. Category: Business Analyst learning.
